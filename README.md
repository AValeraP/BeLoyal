Aplicación TPV para el negocio BeLoyal.

Para usarla previamente debemos tener instalado XAMPP, Apache y MySQL, con una base de datos be_loyal en esta última para poder hacer la conexión.
Una vez todo instalado y encendido Apache y MySQL para acceder se deberá abrir localhost en el navegador y seleccionar la carpeta BeLoyal, que redirigirá al usuario final al panel de login.

La aplicación cuenta con usuario empleado que registra las ventas y un usuario admin que monitoriza el total de ventas, controla el stock de productos de consumo y administra los empleados.
